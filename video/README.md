# Видеоуроки курса

Файлы уроков модуля обучения. Плеер на странице модулей (`moduli.html`, секция `#obuchenie`)
берёт путь из атрибута `data-src` у кнопки урока в списке `#v-items`:

    video/lesson-1.mp4 ... video/lesson-8.mp4

Форматы: MP4 (H.264 + AAC), 1280×720 и выше.

Если урок размещён во внешнем хранилище или на видеохостинге, вместо `data-src`
укажите у кнопки атрибут `data-embed` с URL для вставки — плеер подключит `<iframe>`.

Пока файла нет, плеер показывает уведомление о том, что запись не размещена.
